PERSONAL LEDGER — FRESH ANDROID PROJECT

Features:
- Person name, amount, Given / Received, transaction reason
- Automatic date and time
- Total Given, Total Received and Net Balance
- Search by name or reason
- Delete selected transactions with confirmation
- Offline SQLite storage inside the app's private data directory

FREE GITHUB APK BUILD:
1. Upload all project contents to the root of your GitHub repository.
2. Make sure .github/workflows/android.yml exists at that exact path.
3. Open Actions and select "Build Personal Ledger APK".
4. Click Run workflow on branch main.
5. After success, download the artifact "personal-ledger-android-apk".
6. Extract the artifact ZIP and install the APK on your Android phone.

Package: org.personaltools.personalledger
Minimum Android: 6.0 (API 23)
Build: Debug APK for personal installation

Note: App data is stored locally. Back up important records before uninstalling the app.
